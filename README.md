# agri-management-db
# Ауыл шаруашылығын басқару жүйесі (Agri Management DB)

Бұл жоба – ауыл шаруашылығын басқаруға арналған деректер қорының жобасы. 
Жүйе егін шаруашылығы мен мал шаруашылығын толық қамтиды.

## 📌 Жобаның мақсаты
Ферма қызметін автоматтандыру:
- егін егу және жинау
- мал топтарын басқару
- өнімді есепке алу
- қойма есебі
- сату операциялары
- қызметкерлерді басқару

## 🗂 Негізгі кестелер

### Егін шаруашылығы:
- farm
- field
- crop
- planting
- harvest
- crop_operation
- season

### Мал шаруашылығы:
- livestock_group
- animal
- health_record

### Қойма және сату:
- product
- inventory_lot
- sale
- sale_item

### Қызметкерлер:
- employee

---

## 🔗 Деректер тұтастығы

- Әр кестеде PRIMARY KEY бар
- Барлық байланыстар FOREIGN KEY арқылы орнатылған
- UNIQUE және CHECK шектеулері қолданылған
- Деректер қайталануын болдырмайды
- Бизнес-модель толық сипатталған
